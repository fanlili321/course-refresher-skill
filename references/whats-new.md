# 本年度新变化清单（第 9 类维度）

旧稿的问题分两种：**说错了**（前八类）和**说漏了**——这一年发生的新变化，稿子里完全没有。
这一维度专门抓后者。

## 铁律：只补稿子已经涉及的主题

**不是每本册子都要补每一条。** 判定标准很简单：

- 稿子里**已经讲到这个主题** → 按新变化更新或补充。
  （例：册子讲了跟车投顾组合 → 投顾费优惠、自动止盈就该补）
- 稿子里**根本没有这个主题** → 不补。
  （例：一本纯讲估值指标的册子，不要硬塞投顾费优惠进去）
- 稿子的**定位不覆盖** → 不补，在清单里注明"本册不涉及"。

硬塞新内容会把册子的结构和定位撑坏，比漏掉更糟。清单里每条都要写清"适用于哪类册子"。

## 怎么重新生成这份清单

清单会过期，每次做更新任务前先按下面的方法刷一遍，再对着稿子挑。

1. **按年份捞**：`drive +search --query "2026年"`（换成当年年份）扫一遍，命中的多是含时点判断的卡片。再补 `"今年"`、`"最新"` 各一轮。
2. **按主题捞**：针对稿子实际涉及的主题逐个搜（投顾费、组合功能、小程序、课程书籍、政策制度、新指数品种……）。
3. **看卡片的三个字段定新旧**：
   - `时效性`：`强时效` > `含时点数据` > `长期方法论`，前两类才可能是新变化
   - `版本演变`：直接写明"原X（日期）已被Y取代（日期）"，是最硬的证据
   - `更新记录` / `出处`：日期在近一年内的，就是新增量
4. **回写**：确认过的新变化补进下面的清单，注明依据卡片编号和日期。

## 写进稿子时的注意

- **投顾费优惠等组合层面的事，主语必须是组合**：写"钉系列投顾组合开展了投顾费优惠活动／合并计算年费封顶"，不能写"螺丝钉为大家争取了优惠"（踩第 8 类的费用类红线）。素材库卡片 F3-087 的原话本身主语就是对的，照抄即可。
- 补充内容同样要**贴原文语气**，插在相关段落之后，不要新起一节打断结构。
- 补进去的新变化，在更新清单里单列成 **P3 建议补充**，和"必须改"分开，让用户能单独取舍。
